# Set-up-Proms

Este repositorio es un espacio para practicar y aprender a diseñar prompts efectivos para modelos de lenguaje. Aquí se trabaja en la configuración del entorno, la estructura de prompts y la aplicación de cuatro conceptos clave: instrucciones claras, contexto, roles y alcance/limitaciones.

## ¿De qué se trata este proyecto?

Set-up-Proms es un proyecto de aprendizaje enfocado en mejorar la forma en que se interactúa con asistentes de IA mediante prompts bien diseñados. El objetivo es guiar al usuario para crear prompts más precisos, eficientes y seguros, y al mismo tiempo comprender cómo cada parte del prompt afecta la respuesta del modelo.

## Cómo trabajar aquí

1. Lee y edita el `README.md` para dejar claro el propósito del proyecto.
2. Practica creando prompts estructurados en archivos nuevos o en ejemplos dentro del repositorio.
3. Evalúa las respuestas del modelo según los conceptos clave.
4. Ajusta tus prompts hasta que sean claros, completos y controlados.

## Cómo hacer buenos prompts

Un buen prompt debe:

- Ser directo y fácil de entender.
- Incluir la información necesaria para que el modelo responda correctamente.
- Definir claramente el propósito de la tarea.
- Establecer límites y formato cuando sea necesario.

## Conceptos clave

### 1. Instrucciones claras

Las instrucciones deben decir exactamente qué se espera del modelo. Evita ambigüedades y usa frases concretas como:

- "Resume el texto en dos párrafos."
- "Escribe un ejemplo de prompt para..."
- "Lista los pasos necesarios para..."

### 2. Contexto

Proporciona al modelo la información de fondo necesaria. El contexto incluye datos, ejemplos previos y cualquier detalle relevante que ayude a la tarea.

Ejemplo:

- "Eres un asistente que ayuda a programadores."
- "El proyecto está orientado a diseñar prompts para asistentes de IA."

### 3. Roles

Define quién es el modelo y cuál es su función. Esto puede mejorar la coherencia de la respuesta.

Ejemplo:

- "Actúa como un experto en prompt engineering."
- "Eres un redactor técnico que explica conceptos a principiantes."

### 4. Alcance y limitaciones

Especifica qué debería hacer el modelo y qué no debería hacer. Esto evita respuestas fuera de tema o demasiado amplias.

Ejemplo:

- "Solo responde sobre diseño de prompts, no sobre programación de backend."
- "Limita tu respuesta a 4 puntos principales." 

## Ideas para usar este repositorio

- Comparar prompts ambiguos vs. precisos.
- Documentar buenas prácticas para cada uno de los cuatro conceptos.
- Añadir casos de uso y ejemplos prácticos.
